A terminal program can call `input("Name: ")`, which pauses and returns a string. This browser lesson instead uses `pathfinder = "Nia"`. Do not call blocking `input()` here. Even digits from `input()` are strings and require conversion for arithmetic. Change only the name to `"Ari"` in **main.py**. Press **Run** for `Gear ready for Ari`, then **Submit**.
