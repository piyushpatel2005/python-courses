Level 2 begins at the **Gear Forge**. Each lamp takes four shards. `//` counts complete lamps and `%` counts leftovers. `+`, `-`, `*`, `/`, and `**` add, subtract, multiply, divide, and raise to a power. `/` yields a float; parentheses set order: `(2 + 3) * 4` differs from `2 + 3 * 4`. Keep numbers unquoted. Change only `shards` from `17` to `23` in **main.py**. Press **Run** for `Lamps: 5` and `Spare shards: 3`, then **Submit**.
