The demo changed a map location; now label a different beacon. In Python, you can use double quotes or single quotes for string values. So, following two statements are identical and correct.

```python run
name = 'Charles'
print(name)

name = "Charles"
print(name)
```



You might wonder what is string? String are every information that is textual. When you want to assign a number to variable, you do not need to use any quotes around that number. You can simply assign a value as number.

```python run
name = "Charles"
age = 25
print(name)
print(age)
```

These numeric variables are called integer types. You will learn more about variable types in the upcoming lessons.
