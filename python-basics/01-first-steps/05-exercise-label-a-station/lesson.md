The demo changed a map location; now label a different beacon. Quoted values are strings and unquoted whole numbers are integers. The starter prints both names, so replace only the placeholders in **main.py**. Press **Run** and **Submit**.

## Your Tasks

1. Set `beacon` to `"North beacon"`.
2. Set `beacon_number` to the integer `4` without quotes.
