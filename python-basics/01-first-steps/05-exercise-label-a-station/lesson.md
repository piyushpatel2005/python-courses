At a repair café, write a station card with a name and table number. A quoted value is text; an unquoted whole number is numeric. The starter already prints the named values, so your edits need only replace the two placeholders.

Edit `main.py`, press **Run** to see the station name and number, then **Submit**. Change each assignment separately to see its checkpoint pass.

## Your Tasks

1. Set `station` to the string `"Bike repair"`.
2. Set `table_number` to the integer `4` (without quotes).
