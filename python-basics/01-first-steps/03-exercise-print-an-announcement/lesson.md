You have a map of navigation in the game, but the map needs an opening message and a reminder of where to go next. Write one `print()` call for each line, in the same order you want them to appear.

The lines beginning with `#` in `main.py` are comments. These are notes for you. These are ignored when you run the code, so they will not be printed on the console. Add your code beneath them. 

Press **Run** to check the two output lines, then **Submit**.

## Your Tasks

1. Print `The lantern map is open.` first.
2. Print `Find the first beacon.` as a second line.
