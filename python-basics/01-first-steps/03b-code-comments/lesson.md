Sometimes, you want to leave some notes so that you can come back to the same piece of code and understand it easily. This is done with the help of code comments.

In the last lesson, you saw that Python doesn't print anything starting with pound (`#`) sign. In practice, you will be writing thousands of lines of code and sometimes those code segments might include complicated logic. To make it easier for future yourself to easily understand what you wrote, you would leave comments explaining what you wrote in plain English.

For example, while learning, you might want to leave a note about what the `print()` function does.

```python run
# Print function prints on the console
print("Hi there")
```

If you wrote second line with the `print()` function. It will automatically print it on the next line. 

```python run
# Print always prints on a new line
print("Hi there")
print("I am going to be a Python Programmer!")
```

As you can see, Python doesn't print comments. They are just for understanding. In future, you will be working with other developers like yourself and you want them to understand your code. So, for any complex logic, you would leave this kinds of comments.
