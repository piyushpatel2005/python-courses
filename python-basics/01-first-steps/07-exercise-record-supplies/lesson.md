A seed library needs an inventory entry, not a café menu. The three prefilled variables let you run the program immediately; replace the placeholder values without changing the supplied print probes. A number in quotes is text, even if it looks numeric.

Edit `main.py`, press **Run** to read each value and its type, then **Submit**. Each assignment is one independent checkpoint.

## Your Tasks

1. Set `packet_name` to the string `"Basil seeds"`.
2. Set `packet_count` to the integer `6`.
3. Set `packet_price` to the float `1.75`.
