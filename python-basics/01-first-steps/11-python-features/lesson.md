## Python Features
Here are some features of the language that you can go over. Later lessons will provide practical exposure to these concepts.

- Very concise and readable. Python code tends to be very readable compared to other languages. They do not require curly braces or semi-colon at the end of each statements.
- Dynamic Programming language: This means you do not need to specify the data type with each variable and function declaration. This reduces code verbosity.
- Open source: This means anyone can read the actual code and fix bugs. This means there are lots of contributors and less probability of code bugs.
- Cross-platform: This means the code written in one operating system can still work on another operating system.
- Interpreted language: This means during execution time, each line is interpreted to the machine language one line at a time. Other languages like C++, Java, C# are compiled languages which means they are first compiled into machine code and during execution they only use those machine code. With Python, this extra compilation step is skipped.
- Memory management and Garbage collection: Python has built-in support for Garbage collection. That means we don’t have to worry about allocating and then deallocating memory from our system. Python interpreter will take care of this.
- Packages and Dependency management: It comes with pip which is a tool used to manage dependencies. It also has wide community of developers who have themselves developed lots of general computing packages. That means anything you want to do, most likely someone has written code for that and you can simply reuse their code by importing their packages.
