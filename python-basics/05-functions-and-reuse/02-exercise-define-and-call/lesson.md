# Exercise: announce registration

A class registration desk needs a short announcement. The starter defines `announce()` and calls it at the bottom. Its `pass` statement is a placeholder: Python accepts the empty body, but the call prints nothing.

## Your Tasks

1. Replace `pass` inside `announce()` with a statement that prints `Registration is open`.

Indent your statement four spaces. Keep the supplied call below the function. Run `main.py` to see the message once, then Submit.
