# Exercise: add pages read

A reading log needs a total after someone reads a few more pages. The two numbers passed to the function can change each day, so calculate with the parameters rather than returning a fixed number.

## Your Tasks

1. Complete `total_pages(read, added)` so it returns the sum of its two inputs.

Replace `pass` with a return statement. The supplied print call handles display; don't print inside the function. Run `main.py` to see `11`, then Submit to check other page counts.
