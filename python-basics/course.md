# Learn Python by writing small programs

Start with a message in the console, then give your programs values to work with. The first two sections use a simple game setting for those early examples. From section 3 onward, you will use familiar situations such as counting attendance, checking stock, and preparing a report. You do not need to follow a story to understand what a variable means or why a program makes a decision.

You do not need programming experience. Most lessons let you edit and run code in the browser, and each section ends with a quiz. The final project brings together the decisions, loops, functions, strings, and collections you have practiced.

## What you will learn

1. First steps: Print messages and name values with variables.
2. Values and input: Calculate with numbers, format text, and convert values.
3. Comparisons and decisions: Check conditions and choose what a program does next.
4. Loops: Repeat an action, skip an item, or stop when you have enough.
5. Functions and scope: Reuse a piece of code and understand where its variables are available.
6. Strings: Read, slice, clean, and format text.
7. Lists and tuples: Keep ordered items and read fixed records.
8. Dictionaries and sets: Look up records by key and count unique values.
9. Errors and files: Handle bad values and work with temporary files.
10. Modules and packages: Import Python tools and organize code across files.
11. More function patterns: Try optional recursion, `map()`, and `filter()`.
12. Putting it together: Build a final program and meet classes and objects as vocabulary for future study.

In a coding lesson, read the explanation, edit **main.py**, and use **Run** to inspect the output. **Submit** checks the numbered tasks and tells you what still needs work. Some short reading lessons have runnable examples instead of an editor.
