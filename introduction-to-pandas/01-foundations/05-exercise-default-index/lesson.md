A volunteer hands you a fresh list of visitor counts. You already made a Series from a list; now return its automatically assigned **index** so the desk can label the arrivals. The first count should have index label `0` even when the list length changes.

Edit `main.py`, press **Run** to inspect the result, then **Submit** to check your work.

## Your Task

1. Make `arrival_labels(counts)` return the default index of a Series built from the supplied counts.
