# Furniture-handling analogue

Original synthetic 30-row table. `weight_kg`: float kg, missing means unrecorded; `width_cm`: float cm; `material`: nominal wood/steel. These three inputs are available before handling. `flagged`: observed integer 0/1 target at the fixed 2025-01-15 snapshot. All other fields are complete. Fixed positional slices are 18 train, 6 threshold validation, 6 final test. Glass is used only as an unseen-category query. No actual company outcomes are represented.
