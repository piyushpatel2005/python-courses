# Ordered daily observations

`date`: ISO date string, complete, known on the observation date. `daily_index`: complete integer row index measured in daily positions, aligned with each date; not an actual order-volume target. The demo has 36 consecutive daily observations beginning 2025-01-01; transfer has 60, ending 2025-03-01. Dates provide ordering metadata. No delayed target is fitted, and a one-row gap is not a thirty-day maturity guarantee.
